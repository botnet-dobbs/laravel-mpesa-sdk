# Changelog

All notable changes to `laravel-mpesa-sdk` are documented in this file.

## 2.0.0 - 2026-07-11

All request and response formats verified against the official Safaricom
Daraja documentation. This release is stricter and safer for production use.

### Breaking changes

- Dropped Laravel 10 support. Requires Laravel 11, 12, or 13.
- STK Push requires `AccountReference`, and `Password` / `Timestamp` are
  always generated by the package. Caller-supplied values are ignored.
- New required fields, validated before the HTTP call:
  - B2C: `CommandID`, `QueueTimeOutURL`
  - Account balance, transaction status: `QueueTimeOutURL`
  - Reversal: `RecieverIdentifierType` (Safaricom's spelling, value `"11"`),
    `CommandID`, `Remarks`, `QueueTimeOutURL`
- Blank strings now count as missing and throw `InvalidArgumentException`.
- `b2b()` now targets the real B2B Express Checkout endpoint
  (`/v1/ussdpush/get-msisdn`) and no longer sends `SecurityCredential`.
- `MpesaException` constructor is now `(message, status, body, previous)`
  and `getCode()` always returns 0.
- Malformed 200 responses no longer throw `TypeError`. Code getters return
  `1` and `isSuccessful()` returns `false` instead.

### Fixed

- STK `Password` and `Timestamp` are built from one shared timestamp. They
  could previously drift across a second boundary and be rejected by Daraja.
- Caller input can no longer overwrite generated credentials in payloads.
- App-level `mpesa.endpoints` config overrides now take effect instead of
  being overwritten at boot.

### Security

- Cache keys no longer contain the raw initiator password.
- Access tokens are cached per environment and consumer key. Expect one
  extra OAuth call after upgrading.

### Added

- `MpesaException` now exposes `status` and the response `body`.
- `allowed_callback_ips` config key for your callback middleware.
- Topic guides in `docs/` covering every API, callbacks, configuration,
  and error handling, with config-driven examples.
- Restructured README: quick look, documentation index, client method
  reference, and common questions.
- PHPStan and PHPCS now run in CI.

### Changed

- CI no longer tests Laravel 11. Its releases are blocked by Composer's
  security-advisory policy, so the install step cannot pass. Laravel 11
  stays supported in `composer.json`.

### Removed

- The dead `Mpesa` facade alias in `composer.json`. The facade class was
  already absent in 1.x, so no working code is affected. Inject
  `Botnetdobbs\Mpesa\Contracts\Client` instead.

### Upgrading from 1.x

1. Add `AccountReference` to STK Push calls if you omitted it.
2. Add the newly required fields to B2C, balance, status, and reversal calls.
3. Stop passing `SecurityCredential` to `b2b()`.
4. If you construct `MpesaException` yourself, update to the new signature.
